# Warhammer 40k for Unciv

A full base ruleset that turns Unciv into a grimdark war for the galaxy.

## Features
- **10 playable factions**: Imperium of Man, Adeptus Mechanicus, Adepta Sororitas, Orks, Aeldari, Drukhari, T'au Empire, Chaos, Necrons, Tyranids, each with their own leader, abilities and emblem.
- **Faction units**: every faction has its own versions of the common units, plus unique workers (Grot Oilers, Builder Drones, Canoptek Spyders...).
- **Neutral tech tree + faction branches**: a shared, neutral tree on top and a 9-tech branch for each faction at the bottom.
- **Faction buildings and culture branches**: 5 unique buildings, 6 faction versions of common buildings and a unique policy branch per faction.
- **24 religions**, many pantheon / founder / follower / enhancer beliefs.
- **17 world wonders, 8 natural wonders**, 16 city-states, custom resources and tileset.
- Aircraft and the planet-killing **Exterminatus**.
- Full **Russian translation**.

## Install
In Unciv: **Mods → Download mod from URL**, paste
`https://github.com/Marek123mml/Warhammer40k-Unciv`
and start a new game with the **Warhammer40k** ruleset.

# Warhammer 40k для Unciv

Полный набор правил (base ruleset) по вселенной Warhammer 40 000.

## Возможности
- **10 фракций**: Империум Человечества, Адептус Механикус, Адепта Сороритас, Орки, Аэльдари, Друкхари, Империя Тау, Хаос, Некроны, Тираниды — свои лидеры, способности и символы.
- **Свои юниты у каждой фракции**, включая уникальных работников (Гроты-работяги, Дроны-строители, Каноптековые пауки…).
- **Нейтральное дерево технологий** сверху и **ветка из 9 технологий для каждой фракции** снизу.
- **Постройки фракций и культурные ветки**: 5 уникальных построек, 6 фракционных версий общих построек и своя ветка общественных институтов у каждой фракции.
- **24 религии**, много пантеонов и верований.
- **17 чудес света, 8 природных чудес**, 16 городов-государств, свои ресурсы и тайлсет.
- Авиация и **Экстерминатус**.
- Полный **русский перевод**.

## Установка
В Unciv: **Моды → Скачать мод по ссылке**, вставить
`https://github.com/Marek123mml/Warhammer40k-Unciv`
и начать новую игру с набором правил **Warhammer40k**.
